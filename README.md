# Basic Classifier for Movie Reviews

## Description

This project is a basic classifier for movie reviews, that classifies reviews as either positive or negative, and shows the probability of the generated classification.

The model was trained on the IMDb dataset for movie reviews, along with some additional short examples, Therefore, longer reviews generally produce more reliable results.

The project was written almost entirely using ChatGPT, through a long conversation involving many refinements, along with some manual editing.

It is written in c++ and python. Python is used to train the model, using TF-IDF and logistic regression, and to provide the necessary API.
C++ acts as the orchestrator; it reads the reviews and evaluates them by communicating with the python API, and runs the necessary tests using the Google Test framework.


## Build Instructions

Because it is a docker based project, these are the necessary commands to build and run the project

```
git clone https://github.com/ABX-123/basic-classifier-for-movie-reviews.git
cd basic-classifier-for-movie-reviews
docker build -t image-name .
docker run -it --rm image-name
```

To run the tests in the same container
```
docker exec -it container-id ./build/sentiment_tests
```
Or in a separate container
```
docker run -it --rm image-name ./build/sentiment_tests
```

Note that it can be easily run outside docker, by having the necessary dependencies.
